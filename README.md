# Qiyas_AI

A structured collection of Python scripts and Jupyter notebooks for learning and practicing **data analysis, machine learning, and web scraping**.

## 📂 Structure
- `python/` → Core Python exercises
- `data_analysis/` → NumPy, Pandas, cleaning, visualization
- `machine_learning/` → Regression, classification, ensemble
- `web_scraping/` → Web scraping scripts
- `datasets/` → CSV/TSV datasets
- `challenges/` → Practice challenges
- `notebooks/` → Exploratory and assessment notebooks
